# agentSEM drift

Measurement research on detecting within-person drift in longitudinal behavioral
data, and on how planted authorship contamination affects the indicators.

This is a measurement research tool, not a diagnostic instrument. The binding
claims envelope is in CLAIMS-ENVELOPE.md.

- `paper/` - draft, figures, author notes
- `sim/` - preregistration, metrics, results, robustness plan
- `pilot/` - pilot data work
- `specs/` - specs
- `scripts/` - checks, including the claims lint
